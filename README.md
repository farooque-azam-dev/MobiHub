# MobiHub: E-commerce Website for a Mobile Store

A responsive e-commerce website for a mobile store, showcasing smartphones and accessories with a clean product catalog.

**Live demo:** https://jovial-kelpie-8750c7.netlify.app

## Features

- Responsive layout that works on mobile, tablet and desktop
- - Product catalog covering smartphones and accessories
  - - Interactive features built with JavaScript
    - - WhatsApp contact and ordering links
      - - Clean, organized HTML, CSS and JavaScript code
       
        - ## Tech Stack
       
        - - HTML5
          - - CSS3
            - - Bootstrap
              - - JavaScript
               
                - ## Project Structure
               
                - - index.html : main page
                  - - CSS/ : stylesheets (Bootstrap and custom styles)
                    - - JS/ : JavaScript logic
                      - - Images/ : product images
                       
                        - ## Run Locally
                       
                        - 1. Download or clone this repository
                          2. 2. Open index.html in any modern browser
