# MobiHub: E-commerce Website for a Mobile Store

A responsive e-commerce website for a mobile store, showcasing smartphones and accessories with a clean product catalog.

**Live demo:** https://jovial-kelpie-8750c7.netlify.app

## Features

**Responsive layout** that works on mobile, tablet and desktop.

**Product catalog** covering smartphones and accessories.

**Interactive features** built with JavaScript, including WhatsApp contact and ordering links.

## Tech Stack

HTML5 | CSS3 | Bootstrap | JavaScript

## Project Structure

`index.html` is the main page. The `CSS` folder holds the stylesheets, the `JS` folder holds the JavaScript, and the `Images` folder holds the product images.

## Run Locally

Download or clone this repository and open `index.html` in any modern browser.
